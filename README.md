# 🔗 Link-Checker

**Fake Link Detector** is a smart web application built with **Django** that uses **Natural Language Processing (NLP)** and **Machine Learning** to analyze URLs and determine whether a link is **genuine or suspicious**.

---

## 🧠 How It Works

- Users enter any **link or URL** into the input box.
- The backend processes the link using a **trained classification model**.
- The model checks for phishing patterns, suspicious domains, keyword structure, and metadata.
- Based on probability, the system returns one of:
  - ✅ **Safe Link**
  - ⚠️ **Suspicious Link**
  - ❌ **Phishing/Fake Link**

---

## 🎯 Key Features

- 🧠 Trained ML model (Scikit-learn) for link classification
- 🔍 Real-time URL scanning & analysis
- 📊 Intelligent feedback for users with suggestions
- 💡 Easy-to-use UI built with HTML/CSS/Bootstrap
- 🛡️ Improves digital safety & phishing awareness

---

## 🔬 Technology Stack

- **Framework**: Django (Python)
- **ML Library**: Scikit-learn
- **Vectorization**: CountVectorizer / TF-IDF
- **Frontend**: HTML5, Bootstrap 5
- **Model**: Trained binary classifier (safe vs fake)
